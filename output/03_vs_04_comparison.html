結論：到 07/08 已逼出一條「速度準 ↔ 節奏銳利 ↔ 平滑省力」的取捨前緣，每版各占一個甜蜜點

調參軌跡：04（抖、超速）→ 05（節奏好但抖、超速）→ 06（修超速、最平滑直立，但踏步被磨柔）→ 07（速度雙冠 0.958/0.100、踏步回升）→ 08（節奏/交替/直立三冠，最像教科書 trot，代價是速度準度與平滑退一階）。

• 07 = 速度最準 + 平衡：mean_speed 0.958、speed_error 0.100（皆全場最佳，連 03 都贏），各項無明顯短板。

• 08 = 最像教科書 trot：再把 intra_weight 0.25→0.35、smooth 微升 0.35，拿下 regularity 0.380 / anti_phase 0.358 / uprightness 0.993 三項總冠軍——步態最週期、對角交替最明顯、軀幹最直立。

• 關鍵發現（diagonal_sync 的牆）：加重 intra 把 anti_phase 大幅拉起（0.267→0.358），但 diagonal_sync 只微動（0.544→0.575），邊際效益遞減。diagonal_sync 似乎跟 03 那種較慢的 legacy 步態結構綁定，不是這個旋鈕能輕易補回——03 的 0.712 仍遙遙領先。

• 08 的代價：踏步更賣力 → 速度準度退（speed_error 0.100→0.168）、jerk（0.120→0.133）與 CoT（3.01→4.16）變差。節奏銳利與平滑省力是互斥的兩端。

一句話：沒有單一全贏的版本，而是一條取捨前緣。 要速度準+平衡選 07；要最像 trot（節奏/交替/直立）選 08；要最平滑省力仍是 03；要最平滑的 shaped 版是 06。

怎麼選

  • 要速度最準 + 整體最平衡 → 07。speed_error 0.100 全場最佳，各項無短板。
  • 要最像教科書 trot（最週期、對角交替最明顯、最直立） → 08。regularity/anti_phase/uprightness 三項總冠軍。
  • 要最自然俐落、最省力（raw 觀感最佳） → 03。jerk 0.028 / CoT 1.02 / diagonal_sync 0.712 三項仍最好。
  • 要最平滑的 shaped 版 → 06。jerk 0.087、uprightness 0.989。
  • 04/05 已被 06/07/08 取代，僅留作軌跡對照。

觀察與下一步

  1. 取捨前緣已成形：07（速度準）與 08（節奏銳利）分占兩端，中間靠 smooth / gait / intra 三個權重移動。沒有單一版本全贏。
  2. diagonal_sync 撞牆：intra_weight 0.25→0.35 對它幾乎無效（0.544→0.575）。若真要逼近 03 的 0.712，可能要改量測（contact_threshold 調鬆，捕捉對角腳的短暫同步）或接受「shaped 版 diagonal_sync 上限 ~0.6」這個結構限制。
  3. 若要 07 的速度 + 08 的節奏：可試 07 的 smooth 0.30 配 08 的 intra 0.35（gait 維持 4.5），但 08 已顯示加重 intra 會犧牲速度準度，預期落在兩者之間。是否值得再開一版，看你要不要繼續逼。

指標定義

  • mean_speed / speed_error：前進速度平均、與目標 1.0 的平均絕對誤差。
  • contact_regularity：四腳接觸序列自相關主峰（0–1），越高越週期。
  • anti_phase：兩條對角線「一抬一踏」程度。 / diagonal_sync：同對角兩腳同步度（站著也偏高）。
  • action_jerk：相鄰動作差平方和平均（抽搐）。 / transport_cost：Σ‖action‖²÷距離（省力度）。
  • uprightness：軀幹本體 z 軸的世界垂直分量，1＝完全直立。
