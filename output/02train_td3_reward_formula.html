1. 修正目標（分兩階段）

階段一邊界懲罰 + 動作正則化（ant_reward_modifications.md，原為 Ant-v4 設計）

最初的目標單純是兩件事：

  1. 邊界位置懲罰：防止 Ant 跑出可觀察範圍 —— 從 observation 算出與原點距離，超過閾值後線性懲罰，並用 truncated=True（而非 terminated=True）截斷，避免影響 Q 值 bootstrap。
  2. 動作正則化：讓跑姿更穩健、不像慣性蹬地 —— 加入動作幅度懲罰、相鄰動作差異懲罰（抖動）、接觸力懲罰（重落地）。

階段二修正「站著不動」零風險 attractor（ant_v5_attractor_fix.md，port 到 Ant-v5 後新增）

升級到 Ant-v5 後發現：預設 healthy_reward=1.0 讓「站著不動」變成零風險的 attractor basin —— 不管怎麼調 forward_reward_weight 或加 stillness penalty，agent 都會被吸進「站著」這個局部解（5 次實驗驗證）。解法：

  • 大幅降低 healthy_reward（拿掉「活著就有分」的誘因）
  • 提高 contact_cost_weight（直接懲罰重踩蹬地，改善跑姿）
  • 還原 forward_reward_weight=1.0（不再用壓低速度誘因的方式抑制衝刺）
最終 02train_td3.py 是兩階段目標的合併實作：用環境參數解決「站著不動」問題，再疊加訓練迴圈裡的邊界懲罰與動作正則化解決「跑出邊界」與「跑姿粗暴」問題。

3. 完整 Reward 計算公式

3.1 環境層（傳入 gym.make() 的客製化 Ant-v5 base reward）

Rbase = 1.0 · vx  +  0.1 · 𝟙healthy  −  0.5 · Σ ai²  −  5×10⁻³ · Σ clip(fj, −1, 1)²

對應 forward_reward + healthy_reward − ctrl_cost − contact_cost（Gymnasium Ant-v5 原生公式，僅替換 healthy_reward 與 contact_cost_weight）。

3.2 訓練迴圈層（02 額外疊加的 shaping，02train_td3.py 第 94–105 行）

Rshaping = − 5.0 · max(0, dist − 6.0)  −  0.5 · Σ ai²  −  0.1 · Σ (ai − ai,prev)²

其中 dist = info["distance_from_origin"]；若 dist > 8.0（MAX_RADIUS）則額外設定 truncated = True 並在存入 replay buffer 時視為 terminal。

3.3 最終合併公式

R = Rbase + Rshaping

R = 1.0·vx + 0.1·𝟙healthy  −  1.0·Σai²  −  5×10⁻³·Σclip(fj,−1,1)²  −  5.0·max(0, dist−6.0)  −  0.1·Σ(ai−ai,prev)²
注意：動作幅度懲罰被疊加了兩次 —— 環境內建的 ctrl_cost_weight=0.5（未覆寫，沿用預設）與訓練迴圈裡的 ACTION_PENALTY_WEIGHT=0.5，兩者係數相加後等效權重為 1.0（即上式中粗體的 Σaᵢ² 項）。程式註解裡特別說明「contact_cost 已內建於 Ant-v5 reward，不重複懲罰」，但動作幅度這項實際上確實被疊加計算了兩次。

4. 各子項細節（Python 對照）

# 速度（無上限）

# 邊界距離

# 動作幅度懲罰（env 內建 ctrl_cost + 訓練迴圈 ACTION_PENALTY，合計權重 1.0）
penalty_action_magnitude = 1.0 * sum(action ** 2)

# 相鄰動作差異懲罰（抖動）

# 接觸力懲罰（重落地）

# 邊界懲罰（事前梯度 + 強制截斷）

    truncated = True
